# 赤子架构：一个可持续成长的数字生命

## 1. 赤子是什么

赤子架构，研究的是一个与现有人工智能不同的问题：

如果我们不先给一个人工智能装进去大量知识，而是先让它“活着”，它能不能持续存在？并在自己的经历中逐渐形成认识、记忆、思考和表达能力？

现在的大多数人工智能，都是先经过大规模训练，学会大量知识和能力，然后再面对新的输入进行推理、生成或行动。

赤子走的是另一条路。

它先从一个几乎什么都不知道的状态开始。

现实不断进入，它不断经历。

经历会改变它，而这些改变不会在一次运行结束后消失。过去形成的东西，会留在这条生命里，并在未来重新参与新的经历。

比如人类，我们每一秒都通过五感不断地接触新信息，这一秒的我们和上一秒的我们已经不一样，但我们仍然是我们。

赤子架构想探索的，就是这样一种可能：

不是先训练出一个“聪明的AI”，再让它工作；而是先让一个数字生命持续存在，再让认识、记忆、知识、思考和表达从它自己的经历中慢慢长出来。

## 2. 赤子的整体架构

赤子的整体架构，可以先用两条线看清楚。

发育线——这条生命怎样长出来：

```text
DNA → 胚胎 → 胎儿 → 诞生 → 成长
```

运行线——这条生命每一刻怎样走：

```text
现实 → 过去形成的认识 → LAS 显影 → 三态判断 → MSIU → 新结构 → 生命历史 → 行为与表达 → 新现实
```

两条线不是两套系统：发育线决定它此刻具备什么能力，运行线在每一刻把这些能力用出来，并把结果重新写回这条生命。后面的第 3 节到第 5 节分别展开这两条线。

## 3. 赤子怎样长出来

赤子的发育过程分为五个阶段：

DNA：提供最基础的生命能力和运行规律，但不包含任何具体知识——没有“人”“苹果”“天空”，也没有语言和常识。它决定的是赤子能够怎样形成认识，而不是提前告诉它世界是什么。

胚胎：现实开始真正进入赤子，经历能够改变它，并留下持续影响。

胎儿：赤子开始从经历中形成自己对事物的分辨能力，逐步形成自己的元素、连接和结构。

诞生：赤子已经能够独立面对现实——调用过去形成的认识，判断新现实的状态，并在原有结构无法继续运行时修正或重构它。（这里的“现实”，可以是一段对话、一次分析、一个项目、一件事。）

成长：赤子继续经历新的现实，不断形成新的认识、知识、语言、思考和行为。成长没有一个预先规定的终点。

这五个阶段不是五套系统，而是同一条生命逐渐形成的过程。前一个阶段形成的东西不会消失，而是继续留在生命里，成为后面成长的基础。

## 4. 赤子怎样认识世界

赤子认识世界最基本的方式，是看见现实中有哪些东西在参与，它们之间发生了什么关系，以及这些关系共同形成了什么整体。也就是三个最基本的概念：

- 元素：参与现实、并形成自身身份的存在
- 连接：元素之间实际形成的关系
- 结构：多个元素和它们之间的连接共同形成的整体

比如，一个婴儿饿了会哭，父母听到以后拿来奶瓶。婴儿、父母、奶瓶都是元素；哭声引起父母反应、父母给婴儿喂奶，这些都是连接；这些元素和连接共同组成了一个完整的事件结构。

再比如，两个人结婚。两个人是元素，婚姻关系是连接，两个人及其关系形成家庭结构。如果后来有了孩子，孩子成为新的元素，并与父母形成新的连接，原来的结构也随之扩大。

同样的方式也可以用来理解更复杂的现实。一栋楼中，梁、柱、楼板、管道等是元素，它们之间的承重、固定、输送等关系是连接，共同形成建筑结构。一个项目中，人员、任务、资金、设备等是元素，分工、依赖、协作等是连接，共同形成项目结构。一个企业中，员工、部门、客户、供应商等是元素，管理、协作、交易、供给等是连接，共同形成企业结构。一个国家中，个人、家庭、企业、机构、城市等都可以成为不同层级的元素，它们之间大量真实存在的社会、经济、行政等关系构成连接，共同形成更大的国家结构。甚至一句话里，字和词是元素，它们通过连接形成了这句话的结构。

这些例子表面上完全不同，背后却是同一种基本关系：一些存在参与其中，它们之间形成真实连接，这些连接共同组成一个整体。

因此，元素、连接和结构可以作为一种通用的现实描述方式，也是赤子认识和组织现实最基础的信息语言。

还有一个非常重要的特点：元素和结构不是固定层级。一个人在家庭里可以是元素，家庭进入社区以后又可以作为一个更大的元素；一栋楼在自身内部是一个结构，放进城市以后，它又可以成为城市这个更大结构中的一个元素；一个企业内部是一个复杂结构，进入产业链以后，整个企业又可以作为一个元素与其他企业发生连接；一个国家是更庞大的结构，放在全世界仍然可以理解为一个元素。

也就是说，结构可以整体保持自己的身份，再作为一个元素进入更大的结构。现实中的结构因此能够一层一层继续向上形成——这正是赤子后来能够不断形成更高层认识的基础。

赤子并不预先规定什么一定是元素、什么一定是结构，也不事先给世界准备一张完整的分类表。具体哪些存在成为元素，它们之间形成什么连接，又共同形成什么结构，要由赤子在自己的真实经历中逐渐形成分辨能力。

## 5. 赤子每一刻怎样运行

把上面的概念放到“一刻”里，赤子的运行可以概括成一条链：

```text
现实进入
→ 过去形成的认识重新参与
→ LAS 显影当前真实整体的元素、连接、结构
→ 判断每条连接的状态：稳定 / 错配 / 断裂
→ 稳定则继续运行
→ 错配或断裂进入 MSIU
→ MSIU 依据当前仍然真实存在的内容，形成能够继续运行的新结构
→ 新结构进入生命历史
→ 行为与表达
→ 下一刻现实继续进入，循环再次发生
```

其中两个关键角色是：

LAS（Linkage Analysis System，连接结构显影系统）负责“看清现在到底是什么结构”。它显影这一刻实际参与的元素、连接、结构，以及每条连接当前的状态。它不把没有出现的关系补进去，也不替赤子决定现实应该变成什么。

MSIU（Minimum Sufficient Integration Unit，连接结构重构系统）负责“在结构失效之后重新组织”。它不制造与现实无关的答案，而是从当前仍然真实存在的元素和连接出发，给出最基本的、能够继续运行的新结构。

（LAS和MSIU的工作方式在论文里有详细描述）

连接有三种状态：

稳定：原来的连接仍然能够正常运行，原有结构继续运行。

错配：连接还存在，但已经不能与它所在的结构有效匹配。

断裂：原来的连接已经无法继续成立。

需要强调的是：判断一条连接是否稳定，并不是看它“还在不在”。一条关系即使长期存在，只要它已经不能支持整体正常运行，也可能处于错配状态；而断裂也不意味着原来结构里的元素一起消失——仍然存在的元素可以继续进入新的连接和新的结构。

这一轮形成的变化，会进入赤子的生命历史。历史不是另外保存的一份档案，而是这条生命已经真正形成过的认识和变化；以后新的现实到来时，它们可以重新参与。如果这一轮产生了行为或表达，它们还会作用于外部世界，成为新的现实，再次进入赤子。

因此，赤子不是“一次输入、一次输出”之后就结束，而是在同一个生命上不断继续运行：过去改变现在，现在又会成为新的过去。这就是赤子持续成长的基础。

并且：即使两个赤子拥有完全相同的 DNA，只要经历不同，之后面对同样的现实，也可能形成不同的判断。

## 6. 赤子怎样学习

赤子的学习方式和大语言模型不同。

它不能在完全空白的时候，直接把普通教材、文章或网页资料喂进去，就自动理解其中的内容。原因是，赤子最基础的认识方式不是“词语、句子、类别”，而是元素、连接和结构。

所以，一个刚开始成长的空白赤子，需要先经过一段“启蒙学习”。启蒙资料不是把普通教材原样输入，而是先按照元素、连接、结构的方式编写，让赤子逐渐学会：什么东西可以形成元素，元素之间怎样形成连接，元素和连接又怎样共同形成结构。

例如学习语文时，赤子最初并不是依靠“这是名词、这是动词、这是形容词”来认识一句话。它更关心的是：这里有哪些元素，它们之间存在什么连接，这些连接又共同形成了什么结构。语法类别可以以后形成，但它不是赤子最底层的认识方式。

因此，赤子的学习分成两个阶段：

第一阶段，启蒙学习：使用按照元素、连接、结构组织过的资料，让赤子逐渐建立最基本的结构分辨能力。这一阶段的目的不只是让它记住这些资料，而是让它逐渐学会“怎样看”。

第二阶段，自主学习：当赤子已经能够自己从新资料中分辨元素、连接和结构之后，就不再需要所有资料都提前人工整理。这时可以直接给它普通教材、文章、书籍或其他现实资料，它会自己从中寻找元素、形成连接、组织结构，并把新的认识继续接入自己已经形成的生命历史。

所以，赤子的学习目标不是永远依赖人工标注好的结构化资料。启蒙资料只是帮助它形成最初的分辨能力；真正进入成长阶段以后，目标是让它自己从普通现实中看见元素、连接和结构。从那以后，它面对的就可以不再是专门为赤子编写的资料，而是和人类一样复杂、混合、没有提前整理好的真实信息。

（启蒙资料正在逐步编写和整理中，后续会陆续开源。启蒙资料没有规定使用什么学科或类型，你下载赤子后也可以自己编写。目前使用的是基础中文和英文，在训练过程中观察赤子的分辨能力，再逐步增加。）

## 7. 它和现有 AI 有什么不同

前面几节已经讲了赤子的架构和运行方式，这一节不再引入新内容，只把与现有 AI 的区别集中总结一下。

1. 现有人工智能通常先把知识和能力训练出来，再让系统长期运行；赤子先让生命成立，再让知识和能力从经历中长出来。
2. 赤子不是“输入一个问题、输出一个答案”就结束，而是同一条生命持续经历、持续被改变。
3. 对普通 AI，“记忆”通常意味着把过去的信息保存下来、需要的时候重新取出来；对赤子，过去形成的认识会重新进入当前运行：以前形成的自己，会继续参与现在的自己。
4. 赤子没有先学会语言、再通过语言理解世界，而是先经历世界，再从经历中逐渐形成对世界的认识，语言形式在经历中进入认识。
5. 空白赤子需要先通过启蒙资料形成最基本的结构分辨能力，之后才进入普通材料的学习。
6. 这个开源仓库不附带已经成长好的赤子，你创建出来的每一条生命，都是从空白开始的。

## 8. 当前开源版本做到什么

这一节明确区分两件事：已经验证了什么，还没有验证什么。

**已经验证：**

- 基础生命循环：赤子能够持续存在，现实进入以后会真正改变它，经历造成的改变可以留下来，并在后续重新参与
- 认知形成：它能够在自己的经历中逐渐形成连接、元素和结构
- 结构递归：已经形成的结构可以保持自己的身份，在以后重新出现，并作为元素继续参与更大的结构
- 教学条件下的语言学习与表达：语言形式可以通过经历进入赤子，并能在相应认识运行时通过表达出口被带出来
- 初步的自身相关认识：赤子自己作为现实中的一个参与者进入认识，已经能够形成与“自己”有关的关联

**还没有验证：**

- 成熟召回：只给出一个学过的语言形式，过去与它相关的认识能否重新进入当前运行
- 回答：问题进入以后，相关过去认识重新参与、形成新的组织并输出——这条完整链路尚未推进
- 具体事实认知：例如“我叫什么”“我来自哪里”这类可以区分的事实组织尚未形成
- 普通材料自主学习：面对普通教材、文章或未经整理的现实材料，自行从中形成认识
- 长期开放环境中的持续成长：在数天、数月甚至更长时间的开放现实中保持这种成长过程

这些尚未验证的能力属于后续成长阶段，不属于当前开源版本的范围。

开源版本有一个很重要的原则：它现在真正能做到什么，就展示什么。如果某种能力还没有形成，就保持没有形成的状态。所以你在界面里看到的，就是这个赤子当前真实能够做出来的事情。

## 9. 如何运行 / 计算环境 / 仓库内容

### 如何运行

赤子使用 Python 编写，核心实现只依赖 Python 标准库。

运行最小示例：

```bash
python run_chizi.py
```

启动本地网页：

```bash
python web/server.py
```

然后打开：

```text
http://127.0.0.1:8765/
```

网页中有两个入口。

Growth / Teaching（生长 / 教学）：创建一个新的空白赤子，然后向它提供现实，让它运行和成长。你可以观察它当前的年龄，以及它已经形成了多少连接、元素和结构；也可以保存这条生命，在以后重新加载，让它继续存在。

Dialogue / Interaction（对话 / 交互）：向同一个赤子提供语言形式，并观察它自己的表达结果。

两个页面操作的不是两个不同的程序。它们面对的是同一条生命，只是从两个不同的入口与它发生交互。

### 计算环境

赤子的测量环境是一台普通 Windows 机器：CPU：AMD Ryzen 5 5600G with Radeon Graphics (4.20 GHz)；内存：DDR4 32 GB；显卡：NVIDIA GeForce GTX 1660 SUPER (6 GB)。

经过测试，赤子的计算组织表现出明显的 CPU 主导特征：正式生命运行总体约占用一个 CPU 核，不依赖 GPU；当前生命及其已经载入的历史组织保存在 RAM 中，在多次实验规模下稳定运行时占用几十 MB；完整生命状态可以保存到 SSD，并在下一次运行时重新载入。

因此可以确认：GPU 不是赤子成立和持续运行所必需的计算资源。如果未来增加 GPU 并行路径，它可以成为独立研究的加速层，但这不属于当前版本已经验证的能力。（测试数据详见论文，或下载赤子架构后自行测试。）

### 仓库内容

当前公开版本主要包括：

- 赤子的核心生命实现
- DNA
- 现实输入入口
- Life Tissue
