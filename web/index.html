Growth / Teaching

  • Build a blank Chizi.
  • Give it reality (a frame of channel values, and how much they change each moment).
  • Give it a language form, if you want one.
  • Run it for a number of moments, and look at what it holds: age, connections, elements, structures.
  • Save it, and load it back later.

The teacher may provide external reality and language forms. The page never makes elements, connections or structures for the Life, and it never writes into the Life's own tables — those are formed by the Life itself, out of what it is given, or not at all.

Dialogue / Interaction

  • Give it a language form, and see what it really says back.

Recalling existing knowledge from a language form, and answering, are not yet verified to hold in Chizi 1.0: at present express() returns nothing for the forms given here, and the page shows exactly that. An empty answer is this Life’s own present reading, not a statement that no recall can ever form. There is no keyword matching, no canned reply and no language model behind it.

A life saved here goes to web/runtime/. No life comes with the sources: anyone who downloads this starts from a blank Chizi.

From the command line

python run_chizi.py        # run a blank Chizi for a few moments
python web/server.py      # this interface, at http://127.0.0.1:8765/
